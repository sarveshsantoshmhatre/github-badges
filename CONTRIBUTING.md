# Contributing

Thanks for helping improve this GitHub achievements guide.

## Before opening a pull request

- Make a focused change that improves accuracy, readability, accessibility, or usefulness.
- Prefer official GitHub documentation for achievement requirements.
- Clearly label community-reported observations and include links to credible sources.
- Do not promise that an action will unlock an achievement; GitHub controls achievement eligibility and display.

## Pull request checklist

- [ ] Explain the problem the change solves.
- [ ] Link relevant sources for factual claims.
- [ ] Check all edited links.
- [ ] Keep the change scoped and easy to review.

## Reporting an issue

Use GitHub Issues to report an incorrect claim, broken link, unclear instruction, or missing source. Include enough detail for someone else to reproduce or verify the problem.
